PHONE FLOW
Search: find a role on selected public employer boards.
Saved: keep jobs, application stages, private notes and follow-up dates.
Apply: review exact details when an authorized employer integration is available.
Profile: choose between a phone draft and an explicit online save.

New people start with a blank profile. There is no country or profession whitelist.
The current interface is English. Search covers selected Greenhouse/Lever boards,
not every worldwide vacancy. LinkedIn support saves a personal-profile link and
opens an explicit search; it is not an OAuth account connection or profile import.

REAL APPLICATIONS
Live Auto Apply is disabled until an authorized employer integration is configured.
A verified live receipt requires documented provider acceptance and an application
ID. Saving a job, opening a form, a self-reported stage or a synthetic test cannot
produce live confirmation. Uncertain requests are not automatically resent.
Stop prevents unsent work; a request already sent may still finish.
