CAREER FINDER — 0.4.0 ANDROID PREVIEW / IPHONE SOURCE
16 November 2026 • UTC

PLATFORMS
Native iPhone (iOS 16+) and Android phones (Android 8/API 26+).
Fresh users start with a blank personal profile. The interface is English.
Primary discovery searches selected public Greenhouse and Lever employer boards
across regions and professions. Choose up to four catalog/custom boards, filter
by role/location/remote, and save a posting into the application workspace.
Coverage is limited to those boards, not every worldwide job or eligibility.
The earlier six-source Saudi research feed remains historical/compatibility data.

HOSTED SERVICE
https://career-finder-service.jazzy-drake-8323.chatgpt.site/connect
Public job search requires no account. Sign in with ChatGPT and generate a
one-use code to connect a private phone workspace. The account page offers
recovery, PDF download, export, phone revocation and cloud deletion.
Hosted version 2 deployed successfully and passed 13 public production checks;
browser sign-in, first workspace creation, the account dashboard and a blank
account export have also been verified. Signed-in native phone acceptance and
the populated account lifecycle remain separate. Live Auto Apply remains disabled.

AUTO APPLY
A configured HTTPS service and supported, employer-authorized connector are
required for live submission. Review the exact profile, PDF and employer choices
before approval. Only an actual provider application ID establishes a confirmed
receipt. This proves API acceptance, not a recruiter decision. Public discovery
does not approve or submit anything. Test results, opened links and manual
"Applied elsewhere" self-reports stay separate from verified live receipts.
