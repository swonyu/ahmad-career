WHAT YOU CAN DO
Find opportunities on selected supported employer boards, save public job links,
keep a reusable profile and PDF, and manage private notes, application stages,
follow-ups and exports. New profiles start blank. The product has no country or
profession whitelist, but search does not cover every worldwide vacancy.
Results can include partial-word matches. Use more specific keywords to narrow
them. Uploaded PDFs are not automatically converted into profile fields.

The existing five tabs remain specific to each platform:
Browser: Search · Saved · Apply · Profile · Settings
iPhone:  Start · Search · Apply · Saved · Settings
Android: Jobs · Apply · Receipts · Profile · Settings

Saving a job, opening an employer link and recording a stage do not confirm an
employer submission. Live Auto Apply requires an authorized employer integration
and explicit approval of the reviewed application. A genuine receipt requires
provider acceptance and an application ID. Uncertain requests are not
automatically resent. Stop prevents unsent work; a sent request may still finish.
