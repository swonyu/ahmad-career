W3C Primary Guidance

WAI-ARIA Authoring Practices Guide, Dialog (Modal) Pattern:
“When a dialog closes, focus returns to the element that invoked the dialog unless either:

The invoking element no longer exists. Then, focus is set on another element that provides logical work flow.”

The assigned remedy (live invoker if still in document, else logical phone-main heading, never steal from an already-focused live control) matches this guidance.

Critique of the Two Remedies

(a) Conditional bookmark wording
Source-confirmed defect: notices that assert a bookmark remains after a record-only deletion are false. Conditional wording that omits the bookmark claim when no bookmark exists is the correct minimal fix. No new issue is introduced provided the condition is evaluated against the post-deletion state and the Arabic strings remain accurate. Privacy boundary is preserved (no record content leaked).

(b) Modal focus cleanup
Source-confirmed defect: focus falls to BODY after the invoker is removed. The assigned rule set is correct and minimal.
Potential residual risk (hypothesis only): if the phone-main heading is not focusable or is not announced as a logical workflow landmark, the fallback may still leave the user without a clear next action. Actual keyboard acceptance is required to confirm.

Smallest High-Value Actual Keyboard Acceptance Set

These five cases cover the replaced-dialog transitions without expanding scope:

Removed invoker (record-only delete)

Retained invoker (cancel or save on a still-present card)

Expect: focus returns to the exact button that opened the dialog.

Current outside focus (never steal)
While a dialog is open, programmatically or via another path move focus to a live control outside the dialog (if the implementation allows it), then close the dialog.
Expect: focus stays on that outside control; the cleanup does not pull it back.

Unsaved / cancelled edits
Open Edit, change a field, Cancel (with or without discard confirmation).
Expect: focus returns to the invoker if it still exists; no data is committed; Arabic labels remain correct.
