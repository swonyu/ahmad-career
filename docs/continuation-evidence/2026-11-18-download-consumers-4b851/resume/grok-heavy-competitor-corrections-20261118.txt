Matched Benchmark That Could Falsify a Proposed Advantage

Same set of 10 public Greenhouse/Lever postings, same user profile, same language (Arabic + English).
Measure: (1) time to reach a truthful partial/stale status with board hand-off, (2) whether a self-entered stage survives export/reimport without inventing employer confirmation, (3) recovery of unfinished note after simulated interruption, (4) physical VoiceOver/TalkBack completion of the status update without focus theft.
If a competitor completes the same tasks with equal or better accuracy and less user effort on the same samples, the claimed advantage is falsified. No such matched run has been performed here.
