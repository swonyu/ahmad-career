# App icon
Original vector geometry: a cream briefcase and ascending path on forest green, with a gold starting point. No third-party assets, portrait or personal data.

The iOS asset is 1024×1024 opaque RGB PNG, with square outer corners for system masking. macOS sizes range from16to1024 pixels. The same vector geometry supplies the web icon.

Regenerate with the system Swift/AppKit tools: `swift design/render-icon.swift /tmp/career-icons`, then copy the generated PNGs into the app icon asset set. Verify dimensions, opacity and catalog compilation before release.
